# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Report them privately instead, using either:

- GitHub's private vulnerability reporting: open the repository's **Security**
  tab and click **Report a vulnerability**, or
- email to [security@datologyai.com](mailto:security@datologyai.com).

Please include as much of the following as you can:

- the affected version or commit
- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- any suggested fix or mitigation

We will acknowledge your report within three business days and keep you
informed as we investigate and work on a fix. Please give us a reasonable
amount of time to release a fix before disclosing the issue publicly.

## Supported versions

Security fixes are made against the latest release on
[PyPI](https://pypi.org/project/zephon/). Please confirm the issue still
reproduces on the latest release before reporting.
